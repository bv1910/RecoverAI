# Remix of Remix of Remix of Remix of RecoverAI Welcome Portal

Build the RecoverAI login page with a polished fintech design. Use a blue gradient left panel and clean white right panel. Show “Welcome to RecoverAI”, role selection (Merchant / Customer), email/phone option, and a real “Continue with Google” OAuth button. After Google login, redirect Merchant to /merchant and Customer to /customer. Use Lovable Cloud authentication. Keep the design responsive and do not build the dashboards yet.
